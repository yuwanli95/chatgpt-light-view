# ChatGPT 精简显示

仅显示最近的会话轮次和工具卡片，默认各保留 5 条，支持中文界面和一键恢复。

## 安装

1. Chrome 地址栏输入 `chrome://extensions`。
2. 打开右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本文件所在目录 `C:\Users\NINGMEI\Downloads\chatgpt-light-view`，不要选择 ZIP。
5. 刷新已打开的 ChatGPT 聊天页面，再点击扩展图标。

## 更新到 1.0.3

若之前加载的是本目录，在 `chrome://extensions` 找到“ChatGPT 精简显示”，点击重新加载，再刷新聊天网页。弹窗应显示“版本 1.0.3”。若加载的是其他解压目录，请改为加载更新后的目录。

1.0.3 根据用户保存的实际页面，增加 `data-talvt-turn-state` 完整问答容器和 MCP 应用卡片识别，隐藏范围包含卡片标题、加载占位和 iframe。使用“同步Apifox进度.html”验证：识别 5 轮会话、412 张卡片，默认保留 5 轮和最近 5 张卡片；用户提问、最终回复和输入框保持可见。保留两轮、零卡片和恢复全部显示也通过验证。

1.0.2 为读取页面、读取设置及保存设置增加 5 秒超时提示，避免一直显示“正在读取页面…”。打开弹窗改为读取最近一次统计，不再重复扫描整段聊天；页面变动仍会自动更新统计。“卡片识别帮助”是始终显示的帮助入口，不是检测结果，请以其上方状态文字为准。仍显示零轮次时，点击“查看识别诊断”，复制已选中的内容发给开发者，以便根据实际节点标记修复。诊断只包含结构标记和数量，不读取聊天正文、链接或输入内容，也不会自动上传。

此版本补充了 `data-turn` 轮次标记，修复同一 article 内多条消息被合并的问题，并兼容带 Markdown 结果、无边框折叠容器和只有调用按钮的工具卡片。这些兼容场景通过模拟页面验证；用户真实页面的识别结果仍需核对。

## 使用

- 会话一轮指一次用户提问及后续回复，默认保留最近 5 轮。
- 卡片在当前保留的会话范围内，按页面顺序保留最近 5 张；设为 0 隐藏全部已识别卡片。
- 点击“保存并应用”保存数量，所有 ChatGPT 标签页共享此偏好。
- “临时显示全部”只影响当前标签页，不改数量设置；再次点击恢复精简。
- 关闭“启用精简显示”并保存，即恢复所有内容。
- 自动识别采用工具标记和 read/write 卡片标题。没有命中时，展开“卡片识别帮助”并点“手动识别卡片”。
- 点卡片空白处，检查绿色边框；按 ↑ 扩大、↓ 缩小，Enter 确认，Esc 取消。确认前核对同类组件数量，避免选择通用布局容器。
- 手动识别规则只记录节点结构，不记录聊天文字；不准确时可“重置手动识别”。
- 可识别的待处理授权卡片保留可见，因此显示数量可能超过设定值。

## 实现和限制

基于 Chrome Manifest V3 和站点内容脚本，只运行在 `chatgpt.com`、`chat.openai.com`，不发送网络请求，不读取账号凭据。

通过 CSS 隐藏节点，减少旧内容的布局与绘制工作；保留 DOM 和网页原有状态，便于恢复。不会减少 ChatGPT 服务端返回量、内部 React 节点或已经占用的内存，无法保证解决页面加载之前的卡死。

隐藏范围以网页已加载的内容为准。ChatGPT 的页面结构没有公开稳定契约，自动规则可能漏识别，届时需要手动点选或更新规则。用户提供的保存页面已通过实际结构验证；实时 Chrome 标签页仍未连接，刷新后的在线状态需要在扩展弹窗核对。

技术参考：[Chrome 内容脚本](https://developer.chrome.com/docs/extensions/reference/manifest/content-scripts)、[Chrome 存储 API](https://developer.chrome.com/docs/extensions/reference/api/storage)。
